# Восстановление проекта GIFTLY

Получены оригинальные исходники из репозитория существующего Sites, включая изображения, шрифты и историю Git. Это восстановление, а не воссоздание по скриншотам. Исходная точка: `1616a1b` (версия сайта 3). Публичный сайт не изменялся.

## Продолжение разработки и GitHub

В комплекте: архив исходников, автономный `giftly-preview.html` и `giftly-history.bundle` с историей. Для сохранения истории:

```bash
git clone giftly-history.bundle giftly
cd giftly
git remote rename origin recovery
git remote add origin https://github.com/YOUR_ACCOUNT/giftly.git
git push -u origin main
npm ci
npm run dev
```

Создайте пустой GitHub-репозиторий без README. Bundle не содержит ключей доступа. GitHub Actions запускает проверку и сборку; публикации в workflow нет. Не подключайте автоматический деплой до согласования. `.openai/hosting.json` сохраняет идентификатор существующего сайта.

Telegram сохранён из оригинального проекта: `@bebebebebra`. Корзина формирует заказ: покупатель копирует текст, открывает чат, вставляет и самостоятельно отправляет сообщение. Отправка сообщений и онлайн-оплата не выполняются. Реальные цены, комплектации и контакт необходимо подтвердить перед коммерческим запуском.

Предпросмотр автономен: скачайте HTML и откройте его в браузере. Для ежедневной разработки используйте Vite. В среде восстановления отсутствует поддерживаемый браузерный инструмент; визуальная проверка мобильных экранов остаётся открытой.

# GIFTLY — демонстрационный магазин подарков

Полноценное браузерное приложение: React 19, TypeScript, Vite 6, Tailwind CSS 4 и Motion. Без сервера, аккаунтов, платежей, аналитики и отправки данных.

## Быстрый просмотр

Откройте `giftly-preview.html` в современном браузере. Это отдельный автономный файл: код, изображения и шрифты встроены. Он подготовлен для демонстрации и не требует интернета. Если браузер запрещает буфер обмена для локальных файлов, корзина покажет текст для ручного копирования. Поддержка сохранения localStorage при открытии через `file://` зависит от браузера; обычная версия через HTTP/HTTPS сохраняет корзину между посещениями.

## Запуск исходников

Нужен Node.js 24.15+ (ветка 24 LTS) или 22.22.2+ (ветка 22 LTS) и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, указанный Vite в терминале. Для проверки и производственной сборки:

```bash
npm run check
npm run build
npm run preview
```

После сборки папка `dist/` готова к статическому HTTPS-хостингу. Существующая версия опубликована в Sites; локальные изменения автоматически не публикуются. HashRouter обеспечивает переходы и обновление страниц без серверных правил перенаправления. Развёртывайте `dist/` в корне домена; для вложенного пути потребуется изменить абсолютные пути к изображениям и шрифтам.

## Адаптация под нового клиента

1. В `src/config/store.ts` замените название, логотип (файл в `public/`), email, Telegram, социальные ссылки, категории, ценовые диапазоны и цвета.
2. В `src/config/products.ts` замените восемь примеров своими товарами. `id` должен быть уникальным и стабильным: он используется в URL и сохранённой корзине. `price` — целое число рублей; `contents` — список состава. Фотографии положите в `public/images/`, в `image` укажите `/images/имя.jpg`. Для разных товаров используйте разные фотографии.
3. В `src/config/content.ts` отредактируйте тексты главной страницы, каталога и подвала. Заголовки разделены на обычную и курсивную части. Сохраняйте близкую длину, чтобы композиция оставалась выразительной.
4. В `src/styles.css` при необходимости настройте типографику и сетку. Цвета из конфигурации применяются как CSS-переменные. Шрифты подключены локально в `src/fonts.css`, лицензии лежат в `public/fonts/`.
5. В `index.html` обновите title, description, Open Graph и favicon. Для публикации задайте абсолютный HTTPS-адрес картинки `og:image` и добавьте `og:url` с вашим доменом. Для отдельной индексации товаров в поиске следующим этапом потребуется пререндеринг или маршрутизация с серверной отдачей HTML; текущая версия — SPA с hash-маршрутами.
6. При полной смене клиента измените `CART_KEY` в `src/cart.ts`, чтобы старые позиции не совпадали с новыми. Для реальных продаж замените демонстрационные контакты, составы, фотографии и информационные пометки, согласуйте условия продажи и доставки.
7. Выполните `npm run check`, затем `npm run build`. Проверьте визуально при ширинах 360, 390, 768 и 1440 px, работу клавиатуры, копирование и переход в настоящий чат продавца.

Компоненты находятся в `src/components/`, страницы — в `src/pages/`. Переписывать компоненты при обычной смене контента не нужно. Универсальные подписи интерфейса на русском расположены в соответствующих компонентах.

## Telegram

В `src/config/store.ts` задайте:

```ts
telegram: 'your_shop_username', // без @ и https://t.me/
```

В текущем демо по просьбе владельца указан Telegram `@bebebebebra`. Для другого клиента замените `telegram` и ссылку Telegram в `socials`; пустое значение `telegram` отключает переход из корзины. При заполненном корректном username корзина предлагает две отдельные операции: скопировать заказ и открыть `https://t.me/username`. Покупатель самостоятельно вставляет и отправляет текст. Автоматического заполнения Telegram, ботов и Telegram API нет. При недоступном буфере обмена появляется поле ручного копирования.

## Дизайн

Рассматривались три направления:

| Направление                    | Эстетика                                          | Соответствие подаркам                  | Удобство                                    |
| ------------------------------ | ------------------------------------------------- | -------------------------------------- | ------------------------------------------- |
| Светлый editorial              | Тёплая бумага, serif, предметная съёмка           | Тактильность, забота, личное отношение | Самая ясная и спокойная навигация           |
| Тёмный бутик                   | Графит, направленный свет, драматичная композиция | Выразительность и торжественность      | Менее универсален для повседневных подарков |
| Художественная розовая витрина | Крупные цветовые поля, натюрморты                 | Эмоциональность и лёгкость             | Более узкое настроение коллекции            |

Выбран **Contemporary Editorial Luxury** на светлой основе. Главная — последовательность самостоятельных композиций; каталог — привычная удобная сетка.

Палитра: `#F8F6F2`, `#F0EBE3`, `#242424`, `#D6B7B2`, `#8A6F5A`. Шрифты: Cormorant Garamond и Manrope, с кириллицей, SIL OFL. Отступы секций 65 px на мобильных и 100–120 px на десктопе. Контентные поля 5–6%. Кнопки прямоугольные, высота обычно 48–52 px. Фото товаров 4:5; редакционные блоки имеют собственные пропорции. Появление секций мягкое, однократное; увеличение фото деликатное. Настройка reduced motion учитывается.

## Изображения и лицензии

Изображения специально сгенерированы для этого демо, не являются фотографиями реальных предлагаемых товаров и не содержат водяных знаков. У каждого из восьми товаров своё изображение. Изображение «Медленного утра» повторяется в hero как главный набор бренда. Все используемые изображения хранятся локально и сжаты в JPEG. Внешних фотосервисов, трекеров и сетевых шрифтов в приложении нет.

## Проверки и пределы

`npm run check` проверяет данные товаров, изображения, очистку повреждённой корзины, суммы и текст заказа, затем реальные React-компоненты в jsdom: фильтры, сброс, маршруты, добавление, изменение количества, удаление, пустое состояние, копирование, ограничение Telegram при пустой конфигурации и запись localStorage. Это проверка DOM и логики, а не рендеринга в настоящем браузере.

В доступном окружении нет поддерживаемого браузера для визуальной проверки. Скриншоты, отсутствие горизонтальной прокрутки на реальном устройстве, реальный буфер обмена и внешнее открытие Telegram не проверялись. Перед показом клиенту откройте автономный предпросмотр и выполните эти проверки.

## Автономный предпросмотр

После изменения исходников пересоберите:

```bash
npm run build
npm run standalone
```

Новый файл появится в `work-preview/giftly-preview.html`. Производственный вариант остаётся в `dist/`; автономный HTML служит переносной демонстрацией.

## Улучшение читаемости

Увеличены размеры описаний, цен и подписей каталога. На телефоне строка корзины имеет отдельный ряд для суммы и удаления, а заголовки секций допускают перенос ссылки. Основной текст описаний — 14 px; подписи — преимущественно 12 px. Декоративная строка логотипа остаётся компактной. Изменения проверены сборкой; браузерная визуальная проверка пока недоступна.
