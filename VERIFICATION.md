# Проверка после восстановления

Оригинальный проект получен из Sites, базовый коммит 1616a1b. Повторно успешно выполнены `npm ci`, `npm run check`, `npm run build` на Node 24.22.1. DOM-тесты подтверждают каталог, фильтры, карточку, добавление, количество, итог, удаление, сохранение, копирование, запасной текст при отказе буфера, Telegram-ссылку и Escape.

Изменения: мобильные поля 16px для предотвращения автозума iOS; нижний safe-area отступ и overscroll-behavior корзины; инструкция восстановления с историей Git; GitHub Actions без деплоя. Сохранены исходные товары, шрифты, изображения, цвета и композиция.

Визуальная проверка в браузере и на мобильных устройствах НЕ выполнена: в выбранной managed-среде отсутствует поддерживаемый браузерный инструмент. Перед приёмкой проверить 360, 390, 768 и 1440px, горизонтальное переполнение, длинную корзину и Telegram на телефоне. DOM-тесты не проверяют CSS-раскладку. Сообщения продавцу не отправлялись. Сайт не публиковался и исходный удалённый репозиторий не изменялся.

Предпросмотр — автономный HTML с встроенными ресурсами, открываемый локально. Архив исходников и Git bundle позволяют продолжить работу независимо от чата.
