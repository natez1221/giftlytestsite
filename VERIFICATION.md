# Проверка GIFTLY

Успешно выполнено:

- `npm run build`: TypeScript + производственная сборка Vite.
- `npm run check`: восемь товаров, уникальные id и фотографии, доступность файлов, составы и цены, проверка повреждённых данных корзины, восстановление сохранённых позиций, расчёт 2 × 4900 + 3900 = 13700, формат текста заказа.
- DOM-проверка настоящих React-компонентов в jsdom: каталог из восьми товаров, комбинированная фильтрация и сброс, переход к товару, добавление, изменение количества, перерасчёт, копирование, корректная Telegram-ссылка из конфигурации, удаление и пустая корзина, закрытие по Escape, мобильное меню, skip-link, запись localStorage и ручное копирование при отказе буфера.
- Ошибок React или выполнения в DOM-проверках не получено.

Дополнительно проверено:

- Автономный HTML содержит все 11 изображений и локальные шрифты, внешних обязательных ресурсов нет.
- Логика автономного файла запускается с file-URL и открывает каталог в jsdom. В этой DOM-проверке тяжёлые изображения заменены небольшими заглушками, CSS не отрисовывался; это не визуальная проверка.
- Все девять локальных начертаний шрифтов содержат кириллицу.
- Целостность ZIP-архива проверена.

Не выполнено:

- Скриншоты и визуальная проверка в настоящем браузере: поддерживаемый браузерный инструмент недоступен.
- Проверка физических мобильных устройств, горизонтального переполнения и реального буфера обмена.
- Открытие реального Telegram продавца: в конфигурации указан предоставленный владельцем @bebebebebra; сообщения не отправлялись.
- Публикация, подключение домена и проверка по HTTPS: публикация пользователем не разрешена.

Автономный HTML — переносной предпросмотр приложения, а не скриншот. Откройте его в браузере для визуальной оценки. Исходники и производственная сборка доступны в архиве. README содержит инструкцию по адаптации и список проверок перед показом клиенту.
